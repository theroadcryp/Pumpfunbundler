# Pumpfunbundler
Pump fund bundler script JS/TS
This bot creates a token on Pump.fun, and immediately bundles multiple JITO buy transactions into the same block, front-running early trading activity for strategic positioning. THIS IS FOR EDUCATIONAL PURPOSES ONLY

run script: node bot.js,
Create new wallets in menu (current wallets are examples/ delete),
Fund wallets,
choose Dev wallet,
Create token and bundle
